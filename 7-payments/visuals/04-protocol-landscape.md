# The protocol landscape — which one is for what

| Protocol | Built for |
|---|---|
| x402 | One piece of software paying another for a discrete thing — API calls, data, compute |
| AP2 | Agents proving identity and authorization to each other |
| ACP | Agentic shopping checkouts against merchant catalogs |
| MPP | Pre-authorized spending sessions, streamed continuously |

These aren't really competitors fighting for the same job — they overlap at the
edges but solve different problems. If an agent stack is mostly calling APIs,
fetching data, or paying other agents for sub-tasks, x402 is the one that matters.
Real checkouts on a user's behalf are a different protocol and a different
conversation.
