# ~/.claude/CLAUDE.md — illustrative example, not a real config

This file lives outside any project and applies to every session regardless of
which repo you're in. Copy what's useful into your own `~/.claude/CLAUDE.md` — don't
point Claude Code at this copy directly.

## Style
- Prefer 2-space indentation everywhere unless a project's own CLAUDE.md says otherwise.
- Keep PR descriptions under one screen — link out for detail instead of inlining it.

## Workflow
- Always run the project's existing verify/test command before calling something done.
- When a decision could go two reasonable ways, say which one you picked and why — don't silently pick one.
