# TriageBoard

TriageBoard is a tiny production incident dashboard used as the unconfigured side of the Claude Code setup demo.

This snapshot intentionally has no `CLAUDE.md` and no `.claude/` directory. Use it to show what Claude can infer from code alone before project memory, commands, skills, agents, and hooks are added.

## Commands

```sh
pnpm run dev
pnpm test
pnpm run lint
pnpm run verify
```

The dev server runs on `http://localhost:4173`.
